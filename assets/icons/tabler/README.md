# Tabler Icons (subset)

Outline icons vendored from https://github.com/tabler/tabler-icons, tag `v3.49.0` (commit
`bbed884d15354b5cebf2493371f20dc2d5e83eaf`), `icons/outline/<name>.svg`, unmodified. Licence: MIT
(`LICENSE` in this directory, Copyright (c) 2020-2026 Pawel Kuna). The subset is the icons that
`crates/ui-shell/spec/icons.txt` lists; `crates/ui-shell/tools/gen_spec.py` regenerates that list and
`crates/ui-shell/src/icon_table.rs`. No Microsoft icon artwork is used or vendored.
